# UCMS — 简单高效的 PHP 开源 CMS 建站系统

UCMS 是一款简单的内容管理系统，可以非常方便地通过它来快速开发各种企业站、文章站、站群系统。

系统兼容 **PHP 5.2 - PHP 8.0**，在 **Apache、Nginx、IIS** 上都能使用，支持 **MySQL / SQLite** 两种数据库。后台简洁高效，上手容易，结构清晰，管理维护方便。

## 功能特性

### 多级栏目，多站点

栏目支持域名绑定，同一个空间内可以建立多个网站，适合站群与多品牌站点统一管理。

### 伪静态

超级简单的伪静态配置，不必为配置伪静态规则烦恼，也无需忙于生成静态文件。

开启页面缓存后，配合浏览器 304 缓存，不需要每次从服务器加载页面，减少服务器流量消耗。栏目网址均可自定义，支持中文网址，每个页面均能设置缓存时间。

### 栏目字段

每个栏目均可使用独立的数据表。字段添加方便快捷，能迅速完成任意栏目的搭建。

单选框、多选框、列表框、联动分类等超多字段类型，数据来源可以选择任意栏目。

### 后台权限设置

每个栏目、每个用户都能单独设置增删改权限，安全高效。每个栏目、每个字段都能定制详细的 HTML 代码过滤规则。

### 数据库

MySQL / SQLite 双数据库，支持千万级文章数量。

- **MySQL**：推荐文章站、数据量上万的网站使用，安全稳定
- **SQLite**：强烈推荐企业站使用，转移、维护、备份更加方便

### 电脑站 / 手机站，自动适配

开启手机站模式后，能自动识别访客的系统，自动切换到手机版。

可绑定手机站域名，访问手机站域名时自动载入手机模板。

### 其他

- 内置模板引擎，标签支持 `{ }` / `{{ }}` 自定义，避免与 CSS / JS / PHP 代码冲突
- `uri()` 函数，更换环境、开关伪静态时无需修改模板中的网址
- 后台钩子（Hook）机制，方便二次开发扩展
- 自定义页面、栏目批量增加、栏目配置继承与复制
- Markdown 字段、多图字段（支持批量上传与缩略图）
- 后台文章列表支持 Shift 键批量选择

## 环境要求

- PHP >= 5.2（推荐 7.x；1.6 起兼容 PHP 8.0）
- 数据库：MySQL 5.x 或 SQLite
- 扩展：PDO / pdo_mysql / pdo_sqlite（按所选数据库安装）
- Web 服务器：Apache / Nginx / IIS
