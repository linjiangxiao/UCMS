文章排序

按照id从大到小排序 

{{$set=array()}}

{{$set['order']=id desc}}

{{$articles=alist($set)}}

{{loop $articles['list'] as $a}}

    <a href="{{$a['link']}}">{{$a['title']}}</a>

{{/loop}}


文章栏目可以设置默认排序方式,如果文章调用代码里面为设置排序代码,则会使用默认的排序方式


后台可以增加排序字段,建议文章排序是数字越大排越前面

一般文章列表常见的置顶,文章排序等功能都可以使用 

//id从小到大

{{$set['order']=id desc}}

//id从大到小

{{$set['order']=id asc}}



//排序从大到小,并且id从大到小,aorder为排序字段名

{{$set['order']=aorder desc,id desc}}



//排序从小到大,并且id从大到小

{{$set['order']=aorder asc,id desc}}
