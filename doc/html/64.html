uri网址链接

使用uri函数可以自动在网站更换目录,启用停用伪静态后生成正确的网址,方便制作模板 


//如不使用uri 以下链接会在网站更换网站目录或关闭伪静态后链接失效

<a href="/search/">随便一个站内链接</a>



//使用uri后

<a href="{{uri(/search/)}}">随便一个站内链接</a>



更换网站目录后会自动生成



<a href="/网站目录/search/">随便一个站内链接</a>



关闭伪静态后会自动生成

<a href="/index.php/search/">随便一个站内链接</a>
