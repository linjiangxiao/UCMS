自定义百度ueditor编辑器字段

下载Ueditor php utf-8版本 http://ueditor.baidu.com/website/download.html

将安装包解压到后台img目录下 utf8-php更名为ueditor


以下代码保存到后台目录下admin_config.php文件内 

function ucms_ueditor($action='',$name='',$value='') {

    if($action=='output') {

        echo('<script id="'.$name.'" name="'.$name.'" type="text/plain">'.$value.'</script>');

        echo('<script type="text/javascript" src="img/ueditor/ueditor.config.js"></script>');

        echo('<script type="text/javascript" src="img/ueditor/ueditor.all.js"></script>');

        echo('<script type="text/javascript">var ue = UE.getEditor(\''.$name.'\');</script>');

    }

    if($action=='input') {

        if(isset($_POST[$name])) {

            Return $_POST[$name];

        }

        Return '';

    }

    if($action=='show') {

        Return htmlspecialchars($value);

    }

}


后台栏目变量或栏目字段 增加一个自定义字段 修改该字段配置 输入函数名 ucms_ueditor 即可
