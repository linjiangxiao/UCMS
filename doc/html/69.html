后台管理员密码重置

将以下代码保存为任意文件名.php 到网站目录下(不是模板目录),访问后此文件后,admin密码将自动更改为六位数字

如需更改其他管理员密码,请将代码中的第二个admin改成其他管理员名字

更改密码成功后,请将此文件删除 

<?php

require('inc/config.php');

$psd=rand(100000,999999);

$query = $GLOBALS['db'] -> query("UPDATE ".tableex('admin')." 

    SET psd='".password_md5($psd)."' WHERE username='admin'");

if($query) {

	die('new password:'.$psd);

}else {

	die('error');

}
