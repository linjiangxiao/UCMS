文件上传

下载扩展文件 upload.zip 解压后,将upload.php放到网站inc目录下

表单代码: 

<form method=post action="" enctype="multipart/form-data">

	<input type="file" name="pic">

	<input type="submit">

</form>

上传处理代码: 

{{class upload}}

{{$upload_pic=uploadfile('pic')}}

{{$upload_pic['file']}}



如果需要用在表单保存里面:

{{$upload_pic=uploadfile('pic')}}

{{$newarticle['pic']=$upload_pic['file']}}



判断出错信息:

{{$upload_pic=uploadfile('pic')}}

{{if empty($upload_pic['error'])}}

    上传成功 {{$upload_pic['file']}}

{{else}}

    上传失败 {{$upload_pic['error']}}

{{/if}}



uploadfile函数参数:



uploadfile($name,$max_size,$kind,$filedir)



$name 表单名 

$max_size 最大文件大小 单位Kb

$kind 文件上传种类限制 image media file 想要更多的种类可以在upload.php里面修改

$filedir 自定义文件保存的文件夹 需要用/结尾
